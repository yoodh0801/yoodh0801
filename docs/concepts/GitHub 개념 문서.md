## 1. 개요(Overview)
- **정의(Definition):** Git 저장소를 원격으로 호스팅하고, 코드 리뷰·이슈 추적·협업 워크플로우를 통합 제공하는 **웹 기반 개발 협업 플랫폼**
- **등장 배경(Why it exists):** 로컬에만 존재하는 Git 이력을 클라우드에 안전하게 백업하고, 다수의 팀원이 브랜치를 공유 및 소통할 수 있는 중앙 공간 필요
- **핵심 비유:** 개발자들의 클라우드형 공동 작업실이자 온라인 프로젝트 관리 허브

## 2. 핵심 구성 요소(Key Components)
- **Remote Repository(원격 저장소):** GitHub 서버에 위치해 팀원들과 소스코드를 공유하는 중앙 저장 공간
- **Pull Request(PR):** 브랜치 작업 내용을 메인 코드에 반영하기 전, 코드 리뷰와 토론을 요청하는 핵심 협업 기능
- **Issue(이슈):** 버그 제보, 기능 개선 요청, 할 일(Task) 등을 등록하고 추적하는 프로젝트 보드
- **Actions(액션):** 테스트, 빌드, 배포 등의 개발 워크플로우를 자동으로 실행해 주는 CI/CD 도구

## 3. 동작 원리(How It Works)
로컬 PC의 Git 저장소와 원격 GitHub 서버 간의 동기화 및 협업 흐름

1. **Clone:** 원격 GitHub 저장소를 내 로컬 PC로 복제 (git clone)
2. **Push:** 로컬에서 작업한 커밋을 원격 GitHub 저장소로 업로드 (git push)
3. **Pull Request & Merge:** 웹에서 변경 내역을 검토(Review)하고 최종 병합

## 4. 장단점 (Pros & Cons)
- **장점**
    - **강력한 에코시스템:** 다양한 CI/CD(GitHub Actions), 패키지 관리, 서드파티 앱 연동 지원
    - **직관적인 코드 리뷰:** 변경된 코드(Diff)에 직접 댓글을 달고 토론할 수 있는 최적의 UI 제공
    - **글로벌 표준:** 전 세계 가장 많은 개발자와 오픈소스 프로젝트가 모여 있는 표준 플랫폼
- **단점**
    - **클라우드 의존성:** 인터넷 연결이 끊기거나 GitHub 서버 장애 시 원격 기능(PR, 이슈 등) 사용 불가
    - **보안 및 비용:** 엔터프라이즈급 고급 보안 기능이나 대용량 사용 시 유료 플랜 필요

## 5. 활용 사례 및 안티 패턴 (Use Cases & Anti-patterns)
- **적합 (When to use):** 팀 프로젝트 소스코드 원격 공유, 코드 리뷰 기반 협업, 오픈소스 기여 및 관리
- **부적합 (When NOT to use):** 외부 인터넷이 완전히 차단된 폐쇄망 환경 (온프레미스 솔루션 필요)
