# 마크다운 작성 가이드 문서

```markdown
- **작성자:** 유동한
- **최종 수정일:** 2026-11-18
- **상태:** 초안 (Draft)
- **사전 지식:** 기본적인 파일 시스템(폴더, 파일) 및 터미널(CLI) 사용법
- **대상 독자:** 버전 관리 시스템을 처음 접하는 개발자
- **목표 :** 
```

---
## 1. 제목 (Headings)

제목은 `#`의 개수에 따라 크기가 달라집니다 (1~6단계 지원).

```markdown
# 제목 1 (H1)
## 제목 2 (H2)
### 제목 3 (H3)
#### 제목 4 (H4)
##### 제목 5 (H5)
###### 제목 6 (H6)
```

---
## 2. 텍스트 강조 (Text Formatting)

텍스트를 굵게 하거나 기울이거나 취소선을 적용할 수 있습니다.

```markdown
- *기울임 (Italic)* 또는 _기울임_
- **굵게 (Bold)** 또는 __굵게__
- ***기울임 + 굵게***
- ~~취소선 (Strikethrough)~~
- `인라인 코드 (Inline Code)`
```

---
## 3. 목록 (Lists)

순서가 있는 목록과 없는 목록을 작성할 수 있습니다.

### 순서가 없는 목록 (Unordered)
```markdown
* 항목 1
  * 하위 항목 A
  * 하위 항목 B
- 항목 2
+ 항목 3
```

### 순서가 있는 목록 (Ordered)
```markdown
1. 첫 번째 항목
2. 두 번째 항목
3. 세 번째 항목
```

---
## 4. 링크와 이미지 (Links & Images)

웹 링크와 이미지를 간편하게 삽입할 수 있습니다.

```markdown
[구글 바로가기](https://www.google.com)

![대체 텍스트(Alt Text)](https://via.placeholder.com/150)
```

---
## 5. 인용구 (Blockquotes)

다른 사람의 말을 인용하거나 강조하고 싶은 내용을 작성할 때 사용합니다.

```markdown
> 이것은 인용구입니다.
> > 중첩된 인용구도 사용 가능합니다.
```

---
## 6. 코드 블록 (Code Blocks)

여러 줄의 소스 코드를 보기 좋게 표현할 수 있습니다. 사용하려는 언어 이름을 적으면 문법 강조(Syntax Highlighting)가 적용됩니다.

```python
def hello_world():
    print("안녕하세요, 마크다운!")

hello_world()
```

---
## 7. 표 (Tables)

파이프(|)와 하이픈(-)을 사용하여 깔끔한 표를 만들 수 있습니다. 콜론(:)을 이용해 정렬(좌측, 우측, 가운데)을 지정할 수 있습니다.

```markdown
| 이름 | 직업 | 지역 |
| :--- | :---: | ---: |
| 홍길동 | 개발자 | 서울 |
| 김철수 | 디자이너 | 부산 |
```

---
## 8. 수평선 (Horizontal Rules)

구분을 위한 수평선은 별표(*), 하이픈(-), 언더바(_)를 3개 이상 연속으로 쓰면 생성됩니다.

```markdown
---
***
___
```

---
## 9. 체크리스트 (Task Lists)

작업 목록이나 TODO 리스트를 만들 때 사용합니다. 빈칸([])과 체크된 칸([x])으로 표현합니다.

```markdown
- [x] 마크다운 가이드 작성 완료
- [ ] 블로그 포스팅 업로드
- [ ] 코드 리뷰 진행
```

---
## 10. 각주 (Footnotes)

본문 내용에 상세한 설명이나 출처를 각주 형태로 달 수 있습니다.

```markdown
마크다운은 존 그루버(John Gruber)가 개발했습니다[^1].

[^1]: 2004년에 아론 스와츠와 함께 공동 개발했습니다.
```

---
## 11. 정의 목록 (Definition Lists)

용어와 그에 대한 설명을 구조화할 때 사용합니다.

```markdown
마크다운
: 텍스트 기반의 마크업 언어로, 읽고 쓰기 쉬운 것이 특징입니다.

HTML
: 웹 페이지를 만들기 위한 표준 마크업 언어입니다.
```

---
## 12. 수식 표현 (LaTeX Math)

수학 공식이나 과학 기호를 깔끔하게 표현할 수 있습니다. (주로 수식 기호 $를 사용합니다.)

```markdown
인라인 수식: $E = mc^2$

블록 수식:
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

---
## 13. 이모지 단축키 (Emojis)

콜론(:) 사이에 이모지 이름을 넣으면 실제 이모지로 변환됩니다.

```markdown
:smile: :tada: :fire: :rocket:
```

---
## 14. 접기/펼치기 (Details & Summary)

긴 코드나 참고 사항을 깔끔하게 숨겨두고, 클릭해서 펼쳐 볼 수 있게 만듭니다. (HTML 태그 혼용)

```markdown
<details>
<summary>여기를 눌러서 상세 내용을 확인하세요</summary>

숨겨져 있던 텍스트나 코드 블록이 나타납니다!
</details>
```
